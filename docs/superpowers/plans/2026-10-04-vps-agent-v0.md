# vps-agent v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0 of vps-agent: an MCP server over SSH stdio that gives a coding agent rootless, policy-checked access to a VPS (exec, jobs, files, images, sysinfo, managed users), plus the privileged helper and install/uninstall/connect scripts.

**Architecture:** A Cargo workspace with three crates. `vps-agent-core` holds all pure logic (name validation, policy, redaction, truncation, registry) and is unit-tested on any OS. `vps-agent-priv` is the root helper: typed actions over a `System` trait so the actions are testable with a fake. `vps-agent` is the MCP server and admin CLI; every tool is a plain async function, and `server.rs` is a thin `rmcp` adapter over them.

**Tech Stack:** Rust 1.95, static musl binaries (`x86_64-unknown-linux-musl`, `aarch64-unknown-linux-musl`, linked with `rust-lld`), `rmcp` 3.5.0, `tokio`, `serde`/`serde_json`/`toml`, `regex`, `clap`, `image`, `base64`. Bash for scripts.

**Spec:** https://claude.ai/artifact/1vQv3AsDUN71QZ6dUKDjRw ("vps-agent — спецификация v0.1", rev 12). Read it with the docs connector, not a web fetch.

## Global Constraints

- Supported OS: systemd distributions, Debian 12+ and Ubuntu 22.04+; architectures x86_64 and aarch64.
- Language: Rust, static musl binaries, MCP through the official `rmcp` SDK.
- Out of scope for v0: tmux sessions, `screenshot`, `linger`, `service_*`, `nginx apply`, the Claude Code plugin, remote MCP over HTTPS, multi-host multiplexer.
- Paths and modes: `/usr/local/bin/vps-agent` root 0755; `/usr/local/libexec/vps-agent-priv` root 0755; `/etc/vps-agent/policy.toml` root 0644; `/var/lib/vps-agent/` agent 0750; `/var/lib/vps-agent-priv/` root 0700; `/srv/apps/<name>/` owner 0750.
- Managed user = all three: UID in `uid_range` (default 20000–29999), member of `agent-managed`, entry in `/var/lib/vps-agent-priv/users.json` (root, 0600).
- User name regex: `^[a-z][a-z0-9-]{1,30}$`. Home is only `/srv/apps/<name>`. Never `useradd -o`.
- Built-in group deny list: `root`, `sudo`, `wheel`, `adm`, `docker`, `lxd`, `disk`, `shadow`, `systemd-journal`, plus `[deny] groups` from config.
- `exec` returns `exit_code`, head 50 + tail 150 lines, `truncated`, `log_path`; default timeout 60 s. Full output always goes to `/var/lib/vps-agent/logs/`.
- `fs_read` limit 2000 lines. `fs_upload`/`fs_download` limit 20 MB. `view_image` resizes to 1568 px on the long side.
- All output sent to the model is redacted with `redact.patterns` and wrapped in `<untrusted source="...">…</untrusted>`; the server log keeps the original.
- Every tool call is audited to journald with tag `vps-agent`; every helper call with tag `vps-agent-priv`.
- The helper reads config only from `/etc/vps-agent/` and ignores environment variables.
- Scripts depend only on `bash`, `coreutils`, `curl`, `sudo`; they are idempotent and pass `shellcheck` with no warnings.
- Code, identifiers, comments, error messages and tool descriptions are in English.
- **No git commits in this plan.** The author's solo-git rules forbid commits without an explicit command, so tasks end at a passing test run. `D:\ZoSSH` is not a git repository yet; do not `git init` without being asked.

## Decisions where this plan departs from the spec

1. **tmux is not a v0 prerequisite.** tmux sessions are v1, so install.sh only warns when tmux is missing.
2. **`as_user` is checked by the helper, not by sudoers alone.** sudoers can only test group membership. Before any `sudo -u <user>`, `vps-agent` calls a new helper action `user check <name>`, which verifies all three signs.
3. **Adopted users are exempt from the UID-range sign.** Their UID predates the range. For them the helper checks: registry entry with `adopted: true`, recorded UID matches the live UID, UID is not 0, member of `agent-managed`.
4. **`sudo -u <user> -H -- bash -lc` instead of `sudo -u <user> -i --`.** `sudo -i` re-escapes arguments but leaves `$` unescaped, which breaks a wrapper script that uses `$1`/`$2`. `-H` plus a login `bash -l` gives the same environment without that layer.
5. **`ask` mode is advisory.** The server always exposes annotations; it enforces `read-only` and the deny list in every mode. A client that ignores annotations gets `auto` behavior. This is documented in the tool descriptions and README.
6. **minisign is verified only when the `minisign` binary is present.** It is not in the dependency list; SHA-256 is always checked. Without minisign install.sh prints a warning.
7. **`install.sh --from <dir>`** installs from local binaries. No release exists yet, and v0 targets the author's own servers.

## Development environment

The host is Windows 11 with Rust 1.95. WSL is broken and Docker is absent, so there is no local Linux.

- Unit tests run on the Windows host with `cargo test --workspace`. Everything Linux-specific therefore sits behind the `System` trait (helper) or is plain `std::process::Command` argv building (agent), and compiles on Windows.
- Linux binaries are cross-compiled; the first real run happens on a server in Task 15.

## Review Focus

1. **Output containing `</untrusted>`** — a command prints the closing tag to break out of the wrapper. Expected: the tag is neutralized inside the body. Test in Task 4.
2. **Path tricks around the deny list** — `/etc/vps-agent/../vps-agent/policy.toml`, `//etc/shadow`, a symlink pointing at `/etc/shadow`. Expected: denied after normalization and `realpath`. Tests in Task 3 (lexical) and Task 9 (realpath).
3. **Hostile `as_user` values** — `root`, `-rf`, `a;b`, an unmanaged real user. Expected: rejected before any `sudo` is spawned. Tests in Task 7.
4. **Huge or non-UTF-8 output** — `yes | head -c 2G`, `cat /bin/ls`. Expected: bounded memory, lossy decoding, `truncated: true`. Test in Task 7.
5. **Re-running install.sh on an installed host** — expected: `policy.toml` untouched, no duplicate key in `authorized_keys`, exit 0. Check in Task 15.

Also covered where it belongs: two concurrent `user create` calls must not hand out the same UID (registry lock, Task 5).

```rust
use std::fmt;

#[derive(Debug, PartialEq, Eq)]
pub enum NameError {
    Invalid,
    Reserved,
}

impl fmt::Display for NameError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            NameError::Invalid => write!(f, "name must match ^[a-z][a-z0-9-]{{1,30}}$"),
            NameError::Reserved => write!(f, "name is reserved"),
        }
    }
}

pub const RESERVED_USERS: &[&str] = &[
    "root", "agent", "admin", "daemon", "bin", "sys", "sync", "games", "man", "lp", "mail",
    "news", "uucp", "proxy", "www-data", "backup", "list", "irc", "nobody", "sshd", "ubuntu",
    "debian", "messagebus", "syslog", "postfix", "mysql", "postgres", "redis", "nginx",
];

fn shape_ok(name: &str) -> bool {
    let b = name.as_bytes();
    (2..=31).contains(&b.len())
        && b[0].is_ascii_lowercase()
        && b.iter().all(|c| c.is_ascii_lowercase() || c.is_ascii_digit() || *c == b'-')
}

pub fn validate_group_name(name: &str) -> Result<(), NameError> {
    if shape_ok(name) { Ok(()) } else { Err(NameError::Invalid) }
}

pub fn validate_user_name(name: &str) -> Result<(), NameError> {
    validate_group_name(name)?;
    if RESERVED_USERS.contains(&name) || name.starts_with("systemd-") {
        return Err(NameError::Reserved);
    }
    Ok(())
}
```

```rust
use regex::Regex;
use serde::Deserialize;

#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize, Default)]
#[serde(rename_all = "kebab-case")]
pub enum Mode {
    ReadOnly,
    #[default]
    Ask,
    Auto,
}

#[derive(Debug, Clone, Deserialize, Default)]
#[serde(default)]
pub struct Deny {
    pub commands: Vec<String>,
    pub paths: Vec<String>,
    pub groups: Vec<String>,
}

#[derive(Debug, Clone, Deserialize, Default)]
#[serde(default)]
pub struct Redact {
    pub patterns: Vec<String>,
}

fn default_uid_range() -> (u32, u32) {
    (20000, 29999)
}

#[derive(Debug, Clone, Deserialize)]
#[serde(default)]
pub struct Policy {
    pub mode: Mode,
    #[serde(default = "default_uid_range")]
    pub uid_range: (u32, u32),
    pub deny: Deny,
    pub redact: Redact,
}

impl Default for Policy {
    fn default() -> Self {
        Policy { mode: Mode::Ask, uid_range: default_uid_range(), deny: Deny::default(), redact: Redact::default() }
    }
}

pub const BUILTIN_DENY_GROUPS: &[&str] =
    &["root", "sudo", "wheel", "adm", "docker", "lxd", "disk", "shadow", "systemd-journal"];

pub const DEFAULT_POLICY_TOML: &str = r#"mode = "ask"            # read-only | ask | auto
uid_range = [20000, 29999]

[deny]
commands = ['rm\s+-rf\s+/(\s|$)', 'mkfs', 'dd\s+.*of=/dev/']
paths    = ["/etc/shadow", "/root", "/etc/vps-agent"]
groups   = []

[redact]
patterns = ['(?i)(password|secret|token|api[_-]?key)\s*[=:]\s*\S+', '-----BEGIN [A-Z ]*PRIVATE KEY-----']
"#;

impl Policy {
    pub fn from_toml_str(s: &str) -> Result<Policy, String> {
        let p: Policy = toml::from_str(s).map_err(|e| format!("policy.toml: {e}"))?;
        let (lo, hi) = p.uid_range;
        // 1000..60000 keeps the range clear of system accounts and of nobody (65534).
        if lo < 1000 || hi >= 60000 || lo > hi {
            return Err(format!("policy.toml: uid_range [{lo}, {hi}] must satisfy 1000 <= lo <= hi < 60000"));
        }
        Ok(p)
    }

    pub fn load(path: &str) -> Result<Policy, String> {
        let s = std::fs::read_to_string(path).map_err(|e| format!("{path}: {e}"))?;
        Policy::from_toml_str(&s)
    }

    pub fn group_denied(&self, group: &str) -> bool {
        BUILTIN_DENY_GROUPS.contains(&group) || self.deny.groups.iter().any(|g| g == group)
    }
}

pub fn normalize_lexical(path: &str) -> Result<String, String> {
    if !path.starts_with('/') {
        return Err(format!("path must be absolute: {path:?}"));
    }
    let mut parts: Vec<&str> = Vec::new();
    for seg in path.split('/') {
        match seg {
            "" | "." => {}
            ".." => {
                parts.pop();
            }
            s => parts.push(s),
        }
    }
    Ok(format!("/{}", parts.join("/")))
}

pub struct CompiledPolicy {
    pub policy: Policy,
    deny_commands: Vec<Regex>,
    deny_paths: Vec<String>,
    redact: Vec<Regex>,
}

impl CompiledPolicy {
    pub fn new(policy: Policy) -> Result<Self, String> {
        let compile = |v: &[String], what: &str| -> Result<Vec<Regex>, String> {
            v.iter().map(|p| Regex::new(p).map_err(|e| format!("{what} pattern {p:?}: {e}"))).collect()
        };
        let deny_commands = compile(&policy.deny.commands, "deny.commands")?;
        let redact = compile(&policy.redact.patterns, "redact")?;
        let deny_paths = policy.deny.paths.iter().map(|p| normalize_lexical(p)).collect::<Result<_, _>>()?;
        Ok(CompiledPolicy { policy, deny_commands, deny_paths, redact })
    }

    pub fn check_command(&self, cmd: &str) -> Result<(), String> {
        match self.deny_commands.iter().find(|r| r.is_match(cmd)) {
            Some(r) => Err(format!("command denied by policy pattern {:?}", r.as_str())),
            None => Ok(()),
        }
    }

    pub fn check_path(&self, abs_path: &str) -> Result<(), String> {
        let p = normalize_lexical(abs_path)?;
        for d in &self.deny_paths {
            if p == *d || p.starts_with(&format!("{d}/")) {
                return Err(format!("path denied by policy: {d}"));
            }
        }
        Ok(())
    }

    pub fn redact(&self, text: &str) -> String {
        let mut out = text.to_string();
        for r in &self.redact {
            out = r.replace_all(&out, "[REDACTED]").into_owned();
        }
        out
    }
```

```rust
use std::io::{Read, Seek, SeekFrom};
use std::path::Path;

pub const HEAD_LINES: usize = 50;
pub const TAIL_LINES: usize = 150;
const WHOLE_FILE_LIMIT: u64 = 1024 * 1024;
const HEAD_WINDOW: u64 = 256 * 1024;
const TAIL_WINDOW: u64 = 512 * 1024;

pub struct Truncated {
    pub text: String,
    pub truncated: bool,
    pub total_lines: usize,
}

pub fn head_tail(text: &str, head: usize, tail: usize) -> Truncated {
    let lines: Vec<&str> = text.split_inclusive('\n').collect();
    let total = lines.len();
    if total <= head + tail {
        return Truncated { text: text.to_string(), truncated: false, total_lines: total };
    }
    let mut out = String::new();
    out.extend(lines[..head].iter().copied());
    out.push_str(&format!("[... {} lines omitted ...]\n", total - head - tail));
    out.extend(lines[total - tail..].iter().copied());
    Truncated { text: out, truncated: true, total_lines: total }
}

pub fn head_tail_file(path: &Path, head: usize, tail: usize) -> std::io::Result<Truncated> {
    let mut f = std::fs::File::open(path)?;
    let len = f.metadata()?.len();
    if len <= WHOLE_FILE_LIMIT {
        let mut buf = Vec::new();
        f.read_to_end(&mut buf)?;
        return Ok(head_tail(&String::from_utf8_lossy(&buf), head, tail));
    }
    let mut hbuf = vec![0u8; HEAD_WINDOW as usize];
    f.read_exact(&mut hbuf)?;
    f.seek(SeekFrom::Start(len - TAIL_WINDOW))?;
    let mut tbuf = Vec::new();
    f.read_to_end(&mut tbuf)?;
    let htext = String::from_utf8_lossy(&hbuf);
    let ttext = String::from_utf8_lossy(&tbuf);
    let hlines: Vec<&str> = htext.split_inclusive('\n').take(head).collect();
    // The first line of the tail window is almost certainly cut mid-line; drop it.
    let tall: Vec<&str> = ttext.split_inclusive('\n').skip(1).collect();
    let tlines = &tall[tall.len().saturating_sub(tail)..];
    let mut out = String::new();
    out.extend(hlines.iter().copied());
    out.push_str(&format!("[... output omitted, {len} bytes total ...]\n"));
    out.extend(tlines.iter().copied());
    Ok(Truncated { text: out, truncated: true, total_lines: 0 })
}

pub fn wrap_untrusted(source: &str, body: &str) -> String {
    let re = regex::Regex::new(r"(?i)<\s*/\s*untrusted\s*>").unwrap();
    let safe = re.replace_all(body, "<\\/untrusted>");
    let safe = safe.trim_end_matches('\n');
    format!("<untrusted source=\"{source}\">\n{safe}\n</untrusted>")
}
```

```rust
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;
use std::path::{Path, PathBuf};
use std::time::{Duration, Instant};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct UserEntry {
    pub uid: u32,
    pub adopted: bool,
    pub created_at: u64,
}

#[derive(Debug, Default, Serialize, Deserialize)]
pub struct Registry {
    pub users: BTreeMap<String, UserEntry>,
}

impl Registry {
    pub fn load(path: &Path) -> Result<Registry, String> {
        match std::fs::read_to_string(path) {
            Ok(s) => serde_json::from_str(&s).map_err(|e| format!("{}: {e}", path.display())),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(Registry::default()),
            Err(e) => Err(format!("{}: {e}", path.display())),
        }
    }

    pub fn save(&self, path: &Path) -> Result<(), String> {
        let tmp = path.with_extension("json.tmp");
        let body = serde_json::to_string_pretty(self).map_err(|e| e.to_string())?;
        std::fs::write(&tmp, body).map_err(|e| format!("{}: {e}", tmp.display()))?;
        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;
            std::fs::set_permissions(&tmp, std::fs::Permissions::from_mode(0o600))
                .map_err(|e| e.to_string())?;
        }
        std::fs::rename(&tmp, path).map_err(|e| format!("{}: {e}", path.display()))
    }

    pub fn next_free_uid(&self, range: (u32, u32), taken: &dyn Fn(u32) -> bool) -> Option<u32> {
        (range.0..=range.1).find(|uid| !self.users.values().any(|u| u.uid == *uid) && !taken(*uid))
    }
}

pub struct RegistryLock {
    path: PathBuf,
}

impl Drop for RegistryLock {
    fn drop(&mut self) {
        let _ = std::fs::remove_file(&self.path);
    }
}

pub fn lock(dir: &Path) -> Result<RegistryLock, String> {
    let path = dir.join(".lock");
    let deadline = Instant::now() + Duration::from_secs(10);
    loop {
        match std::fs::OpenOptions::new().write(true).create_new(true).open(&path) {
            Ok(_) => return Ok(RegistryLock { path }),
            Err(e) if e.kind() == std::io::ErrorKind::AlreadyExists => {
                let stale = std::fs::metadata(&path)
                    .and_then(|m| m.modified())
                    .ok()
                    .and_then(|t| t.elapsed().ok())
                    .is_some_and(|age| age > Duration::from_secs(60));
                if stale {
                    let _ = std::fs::remove_file(&path);
                    continue;
                }
                if Instant::now() >= deadline {
                    return Err("registry is locked by another vps-agent-priv call".into());
                }
                std::thread::sleep(Duration::from_millis(100));
            }
            Err(e) => return Err(format!("{}: {e}", path.display())),
        }
    }
}
```

```rust
use std::process::{Command, Stdio};

pub trait System {
    fn uid_of(&self, user: &str) -> Option<u32>;
    fn uid_taken(&self, uid: u32) -> bool;
    fn groups_of(&self, user: &str) -> Vec<String>;
    fn group_exists(&self, group: &str) -> bool;
    fn run(&self, program: &str, args: &[&str]) -> Result<(), String>;
    fn now(&self) -> u64;
}

pub struct RealSystem;

// A fixed PATH and an empty environment: the helper must not inherit anything from its caller.
const SAFE_PATH: &str = "/usr/sbin:/usr/bin:/sbin:/bin";

fn output(program: &str, args: &[&str]) -> Option<String> {
    let out = Command::new(program).args(args).env_clear().env("PATH", SAFE_PATH)
        .stdin(Stdio::null()).stderr(Stdio::null()).output().ok()?;
    out.status.success().then(|| String::from_utf8_lossy(&out.stdout).trim().to_string())
}

impl System for RealSystem {
    fn uid_of(&self, user: &str) -> Option<u32> {
        output("id", &["-u", "--", user])?.parse().ok()
    }
    fn uid_taken(&self, uid: u32) -> bool {
        output("getent", &["passwd", &uid.to_string()]).is_some()
    }
    fn groups_of(&self, user: &str) -> Vec<String> {
        output("id", &["-nG", "--", user]).map(|s| s.split_whitespace().map(String::from).collect()).unwrap_or_default()
    }
    fn group_exists(&self, group: &str) -> bool {
        output("getent", &["group", group]).is_some()
    }
    fn run(&self, program: &str, args: &[&str]) -> Result<(), String> {
        let out = Command::new(program).args(args).env_clear().env("PATH", SAFE_PATH)
            .stdin(Stdio::null()).output().map_err(|e| format!("{program}: {e}"))?;
        if out.status.success() {
            Ok(())
        } else {
            Err(format!("{program} exited with {}: {}", out.status, String::from_utf8_lossy(&out.stderr).trim()))
        }
    }
    fn now(&self) -> u64 {
        std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0)
    }
}
```

```rust
use crate::cli::{Action, Shell};
use crate::sys::System;
use serde_json::{json, Value};
use std::path::Path;
use vps_agent_core::names::{validate_group_name, validate_user_name};
use vps_agent_core::paths::MANAGED_GROUP;
use vps_agent_core::policy::Policy;
use vps_agent_core::registry::{lock, Registry, UserEntry};

#[derive(Debug)]
pub enum ActionError {
    Denied(String),
    System(String),
}

pub struct Env<'a> {
    pub sys: &'a dyn System,
    pub policy: &'a Policy,
    pub registry_path: &'a Path,
    pub archive_dir: &'a Path,
    pub apps_dir: &'a str,
}

fn denied<T>(msg: impl Into<String>) -> Result<T, ActionError> {
    Err(ActionError::Denied(msg.into()))
}

pub fn check_managed(env: &Env, reg: &Registry, name: &str) -> Result<(), ActionError> {
    validate_group_name(name).map_err(|e| ActionError::Denied(format!("{name:?}: {e}")))?;
    let Some(entry) = reg.users.get(name) else {
        return denied(format!("{name} is not in the vps-agent registry"));
    };
    let Some(uid) = env.sys.uid_of(name) else {
        return denied(format!("{name} does not exist on this system"));
    };
    if uid == 0 || uid != entry.uid {
        return denied(format!("{name}: live UID {uid} does not match the registry"));
    }
    let (lo, hi) = env.policy.uid_range;
    if !entry.adopted && !(lo..=hi).contains(&uid) {
        return denied(format!("{name}: UID {uid} is outside the managed range {lo}-{hi}"));
    }
    if !env.sys.groups_of(name).iter().any(|g| g == MANAGED_GROUP) {
        return denied(format!("{name} is not a member of {MANAGED_GROUP}"));
    }
    Ok(())
}

pub fn execute(env: &Env, action: &Action) -> Result<Value, ActionError> {
    let dir = env.registry_path.parent().unwrap_or(Path::new("."));
    let _guard = lock(dir).map_err(ActionError::System)?;
    let mut reg = Registry::load(env.registry_path).map_err(ActionError::System)?;
    match action {
        Action::UserList => Ok(Value::Array(
            reg.users.iter().map(|(n, u)| json!({"name": n, "uid": u.uid, "adopted": u.adopted, "created_at": u.created_at})).collect(),
        )),
        Action::UserCheck { name } => {
            check_managed(env, &reg, name)?;
            Ok(json!({"ok": true}))
        }
        Action::UserCreate { name, shell } => {
            validate_user_name(name).map_err(|e| ActionError::Denied(format!("{name:?}: {e}")))?;
            if reg.users.contains_key(name) || env.sys.uid_of(name).is_some() {
                return denied(format!("user {name} already exists"));
            }
            let Some(uid) = reg.next_free_uid(env.policy.uid_range, &|u| env.sys.uid_taken(u)) else {
                return denied("no free UID left in the managed range");
            };
            let home = format!("{}/{name}", env.apps_dir);
            let shell = match shell { Shell::Bash => "/bin/bash", Shell::Nologin => "/usr/sbin/nologin" };
            env.sys.run("useradd", &["--uid", &uid.to_string(), "--user-group", "--create-home",
                "--home-dir", &home, "--shell", shell, "--groups", MANAGED_GROUP, name])
                .map_err(ActionError::System)?;
            env.sys.run("chmod", &["0750", &home]).map_err(ActionError::System)?;
            reg.users.insert(name.clone(), UserEntry { uid, adopted: false, created_at: env.sys.now() });
            reg.save(env.registry_path).map_err(ActionError::System)?;
            Ok(json!({"name": name, "uid": uid, "home": home}))
        }
        Action::UserDelete { name, archive } => {
            check_managed(env, &reg, name)?;
            if reg.users[name].adopted {
                return denied(format!("{name} is an adopted user and cannot be deleted by the agent"));
            }
            // pkill exits 1 when nothing matched; that is not a failure here.
            let _ = env.sys.run("pkill", &["-KILL", "-u", name]);
            let mut archive_path = Value::Null;
            if *archive {
                let file = env.archive_dir.join(format!("{name}-{}.tar.gz", env.sys.now()));
                let file = file.to_string_lossy().into_owned();
                env.sys.run("tar", &["-czf", &file, "-C", env.apps_dir, name]).map_err(ActionError::System)?;
                archive_path = json!(file);
            }
            env.sys.run("userdel", &["--remove", name]).map_err(ActionError::System)?;
            reg.users.remove(name);
            reg.save(env.registry_path).map_err(ActionError::System)?;
            Ok(json!({"deleted": name, "archive": archive_path}))
        }
        Action::GroupAdd { user, group } => {
            check_managed(env, &reg, user)?;
            validate_group_name(group).map_err(|e| ActionError::Denied(format!("{group:?}: {e}")))?;
            if env.policy.group_denied(group) {
                return denied(format!("group {group} is on the deny list"));
            }
            if !env.sys.group_exists(group) {
                return denied(format!("group {group} does not exist"));
            }
            env.sys.run("usermod", &["-aG", group, user]).map_err(ActionError::System)?;
            Ok(json!({"ok": true}))
        }
    }
}
```

```rust
fn audit(line: &str) {
    let _ = Command::new("/usr/bin/logger").args(["-t", "vps-agent-priv", "--", line])
        .env_clear().stdin(Stdio::null()).stdout(Stdio::null()).stderr(Stdio::null()).status();

fn fail(code: u8, args: &[String], msg: &str) -> ExitCode {
    eprintln!("vps-agent-priv: {msg}");
    audit(&serde_json::json!({"args": args, "result": "error", "code": code, "error": msg}).to_string());
    ExitCode::from(code)
}

fn main() -> ExitCode {
    let args: Vec<String> = std::env::args().skip(1).collect();
    let sys = RealSystem;
    if sys.uid_of_self() != 0 {
        eprintln!("vps-agent-priv: must run as root (through sudo)");
        return ExitCode::from(4);
    }
    let action = match cli::parse(&args) {
        Ok(a) => a,
        Err(usage) => return fail(2, &args, &usage),
    };
    let policy = match Policy::load(POLICY_FILE) {
        Ok(p) => p,
        Err(e) => return fail(4, &args, &e),
    };
    let env = Env {
        sys: &sys,
        policy: &policy,
        registry_path: Path::new(REGISTRY_FILE),
        archive_dir: Path::new(ARCHIVE_DIR),
        apps_dir: APPS_DIR,
    };
    match execute(&env, &action) {
        Ok(v) => {
            println!("{v}");
            audit(&serde_json::json!({"args": args, "result": "ok"}).to_string());
            ExitCode::SUCCESS
        }
        Err(ActionError::Denied(m)) => fail(3, &args, &m),
        Err(ActionError::System(m)) => fail(4, &args, &m),
    }
}
```

```rust
use crate::ctx::Ctx;
use vps_agent_core::names::validate_group_name;
use vps_agent_core::paths::AGENT_USER;

pub const SHELL_WRAPPER: &str = r#"cd -- "${1:-$HOME}" || exit 126; exec bash -c "$2""#;

#[derive(Debug, Clone)]
pub enum RunAs {
    Agent,
    Managed(String),
}

pub fn parse_as_user(as_user: Option<&str>) -> Result<RunAs, String> {
    match as_user {
        None | Some("") | Some(AGENT_USER) => Ok(RunAs::Agent),
        Some(name) => {
            // Shape only: adopted users may carry reserved names (ubuntu, www-data).
            // The helper's `user check` decides whether the user is really managed.
            validate_group_name(name).map_err(|e| format!("as_user {name:?}: {e}"))?;
            if name == "root" {
                return Err("as_user root is never allowed".into());
            }
            Ok(RunAs::Managed(name.to_string()))
        }
    }
}

pub async fn resolve(ctx: &Ctx, as_user: Option<&str>) -> Result<RunAs, String> {
    let run_as = parse_as_user(as_user)?;
    if let RunAs::Managed(name) = &run_as {
        let out = tokio::process::Command::new(&ctx.helper[0])
            .args(&ctx.helper[1..]).args(["user", "check", name])
            .output().await.map_err(|e| format!("cannot run the helper: {e}"))?;
        if !out.status.success() {
            return Err(format!("as_user {name}: {}", String::from_utf8_lossy(&out.stderr).trim()));
        }
    }
    Ok(run_as)
}

impl RunAs {
    pub fn name(&self) -> &str {
        match self {
            RunAs::Agent => AGENT_USER,
            RunAs::Managed(n) => n,
        }
    }

    pub fn argv(&self, argv: &[&str]) -> Vec<String> {
        let mut v: Vec<String> = match self {
            RunAs::Agent => vec![],
            RunAs::Managed(n) => ["sudo", "-n", "-u", n, "-H", "--"].iter().map(|s| s.to_string()).collect(),
        };
        v.extend(argv.iter().map(|s| s.to_string()));
        v
    }

    pub fn shell_argv(&self, cwd: Option<&str>, cmd: &str, timeout_secs: Option<u64>) -> Vec<String> {
        let t = timeout_secs.map(|s| s.to_string());
        let mut inner: Vec<&str> = vec![];
        if let Some(t) = &t {
            inner.extend(["timeout", "-k", "5", t.as_str()]);
        }
        inner.extend(["bash", "-lc", SHELL_WRAPPER, "_", cwd.unwrap_or(""), cmd]);
        self.argv(&inner)
    }
}
```

```rust
pub async fn exec(ctx: &Ctx, p: ExecParams) -> ToolResult {
    let started = Instant::now();
    ctx.policy.check_command(&p.cmd)?;
    if let Some(cwd) = &p.cwd {
        ctx.policy.check_path(cwd)?;
    }
    let run_as = resolve(ctx, p.as_user.as_deref()).await?;
```

```rust
pub const PID_MARKER: &str = "__vps_agent_pid ";
// setsid gives the command its own session and process group, so job_kill can signal
// the whole tree with one `kill -- -PID`, whatever sudo does with ptys.
pub const JOB_WRAPPER: &str = r#"exec 2>&1; cd -- "${1:-$HOME}" || exit 126; exec setsid -w bash -c 'echo "__vps_agent_pid $$"; exec bash -c "$1"' _ "$2""#;
const CHUNK_MAX: u64 = 64 * 1024;

pub fn new_job_id() -> String {
    let ms = std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).map(|d| d.as_millis()).unwrap_or(0);
    format!("j{ms:x}{:04x}", std::process::id() & 0xffff)
}

pub fn valid_job_id(id: &str) -> bool {
    let Some(hex) = id.strip_prefix('j') else { return false };
    (8..=24).contains(&hex.len()) && hex.bytes().all(|b| b.is_ascii_digit() || (b'a'..=b'f').contains(&b))
}

pub fn split_pid_line(first_line: &[u8]) -> Option<i32> {
    std::str::from_utf8(first_line).ok()?.strip_prefix(PID_MARKER)?.trim().parse().ok()
}

pub fn read_chunk(path: &Path, offset: u64, max: u64) -> std::io::Result<(Vec<u8>, u64, bool)> {
    use std::io::{Read, Seek, SeekFrom};
    let mut f = std::fs::File::open(path)?;
    let len = f.metadata()?.len();
    let start = offset.min(len);
    f.seek(SeekFrom::Start(start))?;
    let mut buf = Vec::new();
    f.take(max).read_to_end(&mut buf)?;
    let next = start + buf.len() as u64;
    Ok((buf, next, next >= len))
}
```

Behavior of the four tools and the runner, each with its exact mechanics:

- `job_start`: `check_command`, `check_path(cwd)`, `resolve`. Create `<job_dir>/<id>/`, write `meta.json` with `pid`, `runner_pid`, `exit_code`, `finished_at` all `None`. Spawn `setsid -f <current_exe> job-run <id>` with stdin/stdout/stderr null and wait for `setsid` itself (it returns at once). Audit. Return `id: <id>\nlog_path: <job_dir>/<id>/output.log`.
- `job_run(ctx, id)`: load meta; set `runner_pid = std::process::id()` and save. Build argv as `RunAs::argv(&["bash", "-lc", JOB_WRAPPER, "_", cwd_or_empty, cmd])` using the meta's `as_user` through `parse_as_user` (the check already ran in `job_start`). Spawn with stdout piped and stderr null (the wrapper merges 2>&1). Read stdout with a `BufReader`: read the first line with `read_until(b'\n')`; if `split_pid_line` matches, store `pid` in meta and save, otherwise write the line to `output.log`. Then `std::io::copy` the rest into `output.log`. `wait()`, store `exit_code` (`status.code()`, or `128 + signal` from `ExitStatusExt::signal()` under `#[cfg(unix)]`) and `finished_at`, save.
- `job_status`: reject an id failing `valid_job_id`; load meta. Status is `finished` if `exit_code` is set; `running` if `/proc/<runner_pid>` exists; otherwise `lost`. Return `id`, `status`, `exit_code`, `started_at`, `finished_at`, `as_user`, `output_bytes` (size of `output.log`).
- `job_output`: reject a bad id; `read_chunk(output.log, offset.unwrap_or(0), CHUNK_MAX)`; return `next_offset: N\neof: bool\n` followed by `wrap_untrusted("job:<id>", redact(lossy text))`.
- `job_kill`: reject a bad id; load meta; error `job has no recorded pid yet` if `pid` is `None`; error `job already finished` if `exit_code` is set. Signal is `-KILL` when `force == Some(true)`, else `-TERM`. Run `RunAs::argv(&["kill", sig, "--", &format!("-{pid}")])`. Audit. Return `signal sent`.

Meta is saved with the same write-tmp-then-rename pattern as the registry so `job_status` never reads a half-written file.

```rust
pub const MAX_TRANSFER: usize = 20 * 1024 * 1024;

pub fn slice_lines(content: &str, start: usize, limit: usize) -> (String, usize) {
    let lines: Vec<&str> = content.lines().collect();
    let first = start.max(1);
    let mut out = String::new();
    for (i, line) in lines.iter().enumerate().skip(first - 1).take(limit) {
        out.push_str(&format!("{:>6}\t{line}\n", i + 1));
    }
    (out, lines.len())
}

#[derive(Debug)]
pub enum EditError {
    NotFound,
    Ambiguous(usize),
    Identical,
}

impl std::fmt::Display for EditError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            EditError::NotFound => write!(f, "`old` was not found in the file"),
            EditError::Ambiguous(n) => write!(f, "`old` matches {n} times; add context or set replace_all"),
            EditError::Identical => write!(f, "`old` and `new` are identical"),
        }
    }
}

pub fn apply_edit(content: &str, old: &str, new: &str, replace_all: bool) -> Result<String, EditError> {
    if old.is_empty() {
        return Err(EditError::NotFound);
    }
    if old == new {
        return Err(EditError::Identical);
    }
    match content.matches(old).count() {
        0 => Err(EditError::NotFound),
        1 => Ok(content.replacen(old, new, 1)),
        _ if replace_all => Ok(content.replace(old, new)),
        n => Err(EditError::Ambiguous(n)),
    }
}
```

```rust
pub const MAX_SIDE: u32 = 1568;

pub fn fit_within(w: u32, h: u32, max_side: u32) -> (u32, u32) {
    let long = w.max(h);
    if long <= max_side {
        return (w, h);
    }
    let scale = |v: u32| ((v as u64 * max_side as u64) / long as u64).max(1) as u32;
    (scale(w), scale(h))
}

pub fn prepare_image(bytes: &[u8]) -> Result<(String, String), String> {
    use base64::Engine;
    let img = image::load_from_memory(bytes).map_err(|e| format!("not a supported image: {e}"))?;
    let (w, h) = fit_within(img.width(), img.height(), MAX_SIDE);
    let img = if (w, h) == (img.width(), img.height()) {
        img
    } else {
        img.resize_exact(w, h, image::imageops::FilterType::Triangle)
    };
    let mut buf = std::io::Cursor::new(Vec::new());
    img.write_to(&mut buf, image::ImageFormat::Png).map_err(|e| e.to_string())?;
    Ok(("image/png".into(), base64::engine::general_purpose::STANDARD.encode(buf.get_ref())))
}
```

```bash
# UI helpers shared by install.sh and uninstall.sh. Inlined into them by bundle.sh.

UI_LOG="${UI_LOG:-/var/log/vps-agent-install.log}"
UI_STEP=0
UI_TOTAL=0
UI_SPIN_PID=""
UI_TTY=0
if [ -t 1 ] && [ -z "${NO_COLOR:-}" ]; then UI_TTY=1; fi

if [ "$UI_TTY" = 1 ]; then
  C_OK=$'\033[32m' C_WARN=$'\033[33m' C_ERR=$'\033[31m' C_DIM=$'\033[2m' C_BOLD=$'\033[1m' C_OFF=$'\033[0m'
else
  C_OK="" C_WARN="" C_ERR="" C_DIM="" C_BOLD="" C_OFF=""
fi

ui_cleanup() {
  if [ -n "$UI_SPIN_PID" ]; then kill "$UI_SPIN_PID" 2>/dev/null || true; fi
  if [ "$UI_TTY" = 1 ]; then tput cnorm 2>/dev/null || true; fi
  if [ -n "${UI_TMP:-}" ]; then rm -rf "$UI_TMP"; fi
}
trap ui_cleanup EXIT
trap 'ui_cleanup; exit 130' INT

ui_init() {
  UI_TOTAL="$3"
  : >"$UI_LOG" 2>/dev/null || UI_LOG="$(mktemp)"
  printf '%s%s%s %s  %s%s%s\n\n' "$C_BOLD" "$1" "$C_OFF" "$2" "$C_DIM" "$(hostname)" "$C_OFF"
}

step() {
  UI_STEP=$((UI_STEP + 1))
  UI_LABEL="$1"
}

ui_line() { # status-char color message
  printf '%s[%d/%d]%s %s%s%s %s\n' "$C_DIM" "$UI_STEP" "$UI_TOTAL" "$C_OFF" "$2" "$1" "$C_OFF" "$3"
}

ok() { ui_line "✓" "$C_OK" "$1"; }
warn() { ui_line "!" "$C_WARN" "$1"; }

fail() {
  ui_line "✗" "$C_ERR" "$1"
  printf '\n%slast lines of %s:%s\n' "$C_DIM" "$UI_LOG" "$C_OFF" >&2
  tail -n 20 "$UI_LOG" >&2 || true
  exit 1
}

spin() { # label cmd...
  local label="$1" start rc frames='⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏' i=0
  shift
  start=$(date +%s)
  printf '\n$ %s\n' "$*" >>"$UI_LOG"
  if [ "$UI_TTY" = 1 ]; then
    tput civis 2>/dev/null || true
    "$@" >>"$UI_LOG" 2>&1 &
    UI_SPIN_PID=$!
    while kill -0 "$UI_SPIN_PID" 2>/dev/null; do
      printf '\r%s[%d/%d]%s %s %s' "$C_DIM" "$UI_STEP" "$UI_TOTAL" "$C_OFF" "${frames:i%10:1}" "$label"
      i=$((i + 1))
      sleep 0.08
    done
    wait "$UI_SPIN_PID" && rc=0 || rc=$?
    UI_SPIN_PID=""
    printf '\r\033[K'
    tput cnorm 2>/dev/null || true
  else
    "$@" >>"$UI_LOG" 2>&1 && rc=0 || rc=$?
  fi
  if [ "$rc" = 0 ]; then
    ok "$label ${C_DIM}$(($(date +%s) - start))s${C_OFF}"
  else
    fail "$label"
  fi
}

summary() { printf '\n%s\n' "$1"; }
```
